
## Бонусы в заявке

`POST /v1/orders` принимает `bonus_spent` — целое неотрицательное количество бонусов
для списания (1 бонус = 1 ₽). Если поле не передано, списания нет. Клиент выбирает
от 0 до 100% доступной для заявки суммы ползунком; списание ограничено накопленным
балансом и стоимостью заявки. Сервер проверяет баланс в транзакции: при его нехватке
возвращает 409, не создаёт заявку и не очищает набор. Фронт обновляет баланс и просит
выбрать списание заново.

15% за каждый полный набор Экстра начисляются отдельно, становятся доступны после
статуса `done` и могут использоваться в следующих покупках. В текущей заявке их
списать нельзя. Отмена возвращает списанные бонусы и убирает ожидаемое начисление.
`to_pay = total - bonus_spent` используется в подтверждении, истории и Telegram.

Проверка заявок, бонусов и согласования поставщика:

```sh
python -m unittest discover -s backend/tests -v  # из корня репозитория
node --check frontend/groups.js
```
