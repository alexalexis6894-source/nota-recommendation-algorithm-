# НОТА

Веб-приложение для любителей парфюмерии: человек собирает коллекцию своих ароматов (можно по фото флаконов),
а НОТА подбирает новые ароматы под его вкус и предлагает заказать пробники. Работает на nota.staytech.ru, рассчитано на iPhone.

Репозиторий собран для разбора алгоритма рекомендаций экспертом. С чего начать – `EXPERT_PROMPT.md`.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `frontend/` | Весь клиент: чистый JS без сборки, открывается как статика. `frontend/api/*.php` – шлюз на хостинге |
| `backend/` | Python-бэкенд с хостинга: распознавание, поиск по каталогу, похожие ароматы, группы, заказы |
| `mac-worker/` | Обработчик фото на Mac владельца: здесь работает модель распознавания |
| `docs/architecture.md` | Как всё связано, формат ответа модели, ограничения хостинга |
| `lab/` | Обработка фото флаконов для витрины (не связано с распознаванием) |

Каталог ароматов (около 140 тыс. позиций с Фрагрантики) лежит в `backend/data/`, если он залит.
Ключи, токены и данные пользователей в репозиторий не попадают.

## Как открыть локально

Фронт:

```sh
cd frontend
python3 -m http.server 8000
# http://localhost:8000
```

Без бэкенда работает демо-подбор на встроенных ароматах. Распознавание по фото требует бэкенд и обработчик на Mac.

Подбор на полном каталоге, без сервера (проверено, около 3 с на запрос):

```sh
cd backend
python3 -m venv venv && . venv/bin/activate && pip install -r requirements.txt
python ../research/quickstart.py "Eau Sauvage" Dior --mode close --limit 10
python ../research/quickstart.py "Eau Sauvage" Dior --mode new --limit 10
```
