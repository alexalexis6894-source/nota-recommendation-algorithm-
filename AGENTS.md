# Инструкции для агента (Codex)

- Отвечай по-русски.
- Главная тема разбора – алгоритм рекомендаций, задача в `EXPERT_PROMPT.md`.
- Сначала прочитай `docs/architecture.md`, потом код. Общая картина: `README.md`.
- Не добавляй в репозиторий ключи, токены, фото и данные пользователей. Конфиги с секретами – только `*.example`.
- Ограничения продакшена серьёзные (общий хостинг Рег.ру, лимит процессора, Python запускается на каждый запрос).
  Любое предложение по модели проверяй на них, они описаны в `docs/architecture.md`.
- Эксперименты и бенчмарки складывай в `research/`: код, данные замеров, выводы в `research/REPORT.md`.
- Фронт без сборки: правки в `frontend/*.js` и `*.css` проверяются простым статическим сервером.
