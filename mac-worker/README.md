# Обработчик фото на Mac

Здесь работает модель распознавания флаконов (к рекомендациям не относится, нужен для полноты картины): забирает снимки из очереди на хостинге, распознаёт и возвращает
ответ в формате из `docs/architecture.md`. Исходник (`scripts/phone_worker.py` и всё, что он использует)
владелец заливает со своего Mac.
